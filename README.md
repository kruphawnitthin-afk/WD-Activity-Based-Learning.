## Project Overview

This repository contains three selected Web Development Activity-Based Learning case studies. The projects demonstrate webpage design and content organization using HTML and CSS. A consolidated PDF report is included with screenshots of the webpage outputs.

## Selected Case Studies

### 1. Case Study 16 – Travel Agency Website
**Website name:** WanderVista

A travel portal interface that presents popular destinations and holiday packages. The visible sections include:
- Navigation for Home, Destinations, Packages, Itineraries and Contact
- Hero section and trip-planning introduction
- Destination cards
- Featured holiday package cards with trip information

### 2. Case Study 18 – Hotel Reservation Website Interface
**Website name:** Royal Grand Hotel & Resort

A hotel website interface that presents accommodation options and reservation information. The visible sections include:
- Hotel navigation and homepage hero section
- Check-in, check-out and guest availability fields
- Room category cards and amenities
- Hotel facilities
- Room tariff comparison table
- Reservation details form

### 3. Case Study 27 – Business Analytics Dashboard
**Website name:** DataVista

A business dashboard interface that organizes key business information. The visible sections include:
- Sidebar navigation
- Revenue, users, sales and conversion summary cards
- Sales trends chart
- Performance metric indicators
- Revenue by category and top products
- Recent activities and transactions table

## Technologies Used
